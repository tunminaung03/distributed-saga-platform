# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and constructive environment for everyone who participates in the Distributed Saga Platform project, regardless of experience level, background, or identity.

We value open technical discussion, thoughtful feedback, and collaboration that helps improve the project.

## Expected Behavior

Examples of behavior that contribute to a positive environment include:

- Being respectful and considerate in technical discussions and code reviews.
- Providing constructive feedback focused on the code, design, and technical reasoning rather than individuals.
- Accepting differing technical opinions and explaining architectural trade-offs professionally.
- Respecting the time and contributions of maintainers and other participants.
- Sharing knowledge and helping others learn where practical.
- Communicating openly about defects, limitations, and security concerns.

## Unacceptable Behavior

The following behaviors are not acceptable:

- Harassment, discrimination, personal attacks, or abusive language.
- Trolling, deliberate intimidation, or sustained disruptive behavior.
- Publishing another person's private information without permission.
- Deliberately disrupting project discussions or contribution processes.
- Any other conduct that is inappropriate in a professional technical community.

## Scope

This Code of Conduct applies to project spaces, including GitHub issues, pull requests, discussions, code reviews, and other project-related communication.

## Enforcement

The project maintainer is responsible for interpreting and enforcing this Code of Conduct.

The maintainer may remove or edit inappropriate content, close discussions, reject contributions, or restrict participation when necessary to maintain a respectful project environment.

Enforcement decisions will be made with consideration for the circumstances and the impact of the behavior.
